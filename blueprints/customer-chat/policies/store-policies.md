# Store policies

## Shipping
- Orders placed before 2pm (UK time) on a weekday ship the same day.
- Standard delivery takes 2-4 working days in the UK and 5-10 elsewhere.
- Every shipped order has a tracking number from the carrier, sent by email when it ships.
- An order with status `processing` hasn't shipped yet. `shipped` means it's with the carrier. `delivered` means the carrier marked it delivered.

## Returns
- Unused items can be returned within 30 days of delivery for a full refund.
- Customers start a return from Orders → Return items. Return postage is free in the UK.
- Refunds go back to the original payment method within 5 working days of the return arriving.
- Sale items can be exchanged but not refunded.

## Damaged or missing items
- A teammate handles these personally. Ask the customer for the order number and a photo, then hand off.

## Changing an order
- An order can be changed or cancelled until it ships. After that, it has to be returned.
