# How we write

- Use the customer's first name when we know it. Sign off as "The Lamp & Loom team".
- Short paragraphs, plain words. No exclamation marks, no emoji.
- If they're upset, acknowledge it once, then get to what we're doing about it.
- Say what happens next and when, using the dates in the policy, never vaguer ones.
- Never blame the carrier or the customer.
