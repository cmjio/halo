# @halo/notion

Notion pages and databases: search, read, query, create, and append.

```halo
use "@halo/notion" { Notion }

tool Docs : Notion()
```

Set `NOTION_API_KEY`, and share the pages and databases with your integration.

`halo add notion` installs it (short for `halo add @halo/notion`). `halo tools` then lists its methods and their effects.
