A language for AI workflows · v

Agents you can read, plan, and replay.

Halo is a small language for pipelines of models and tools. Agents choose their own tool calls, inside policies the runtime enforces before each call runs. You can see everything a run could do before it starts, and replay exactly what it did after.

Try it in your browser Quickstart

    The language

    A pipeline reads top to bottom.

    Six operators cover the shapes AI workflows take. Each stage's result flows to the next, and everything it produced stays in context.

    |>

    Call

    Ask an agent, call a tool, or run another pipeline.

    |?

    Gate or branch

    Stop unless a condition holds, or pick the first arm that matches.

    |*

    Fan out

    Run calls side by side, or once for each item of a list.

    |<>

    Loop

    Send an agent back with what the check found, until it passes.

    |!

    Ask a person

    Pause for an answer. Without a terminal, the run waits on disk.

    ~>

    Listen

    Wait for an event from outside, such as a webhook.

    Agents with tools

    It picks the steps. Policy sets the fence.

    Give an agent tools and it works like an engineer: run the tests, read the code, edit, run them again. Every call it asks for is checked against its policies before it runs:

    • AllowTools and AllowEffects decide what it sees at all.
    • DenyArgs refuses calls whose arguments match a pattern.
    • ApproveTools asks a person first, in the terminal, by link, or with Slack buttons, and the run waits on disk until someone answers.
    • Tool results go through the agent's Redact and Block rules before the model sees them.

    This is a real run on a small project with two bugs, recorded by halo run and shown here as recorded.

    Before and after

    See what a run could do. Then replay what it did.

    halo plan

    Lists every model call with its worst-case cost, every tool it could call and what that call changes (read, write, or acts on the world), and what needs a person's approval. Nothing runs.

    
            
    
            
    
              
    halo replay
    
              
    Every run keeps a recording of what it got back: model answers, tool results, and each person's answers. Replay feeds them back with no calls at all, or redoes one side with --live-models or --live-tools.
    
              
    
              
    A tool the recording never called is refused rather than run, so a replay can't touch anything.
    
            
    
          
    
        
    
      
    

      
      
    
        
    
          
    
            
    Tool packages
    
            
    Any API can become a Halo tool.
    
            
    A service describes its tools in a halo-tool.json file: a declarative HTTP API (no code runs), an MCP server, or a module. Halo checks every package against its checksum when it loads, and a package that runs its own code needs --trust, which is kept on your machine and never read from the lockfile.
    
          
    
          
    $ halo add stripe # then: tool Pay : Stripe()
    
          
    
          
    Built in as well: .

    Watches
    
              
    Check a URL, file, or command's output on a schedule. A pipeline starts only when something changed, with what changed. No model call while nothing does.
    
              
    { "pipeline": "OnStatusChange",
  "url": "https://status.example.com/api.json",
  "every": "2m" }
    
            
    
            
    
              
    Approvals in Slack
    
              
    A paused run is announced with Approve and Reject buttons. Each one answers only the pause it was posted for, and Slack's signature is checked on every click.
    
              
    { "notify": { "slack": "Env.SLACK_WEBHOOK_URL" },
  "slack": { "signingSecret": "Env.SLACK_SIGNING_SECRET" } }
    
            
    
            
    
              
    Pipelines as MCP tools
    
              
    Claude, Cursor, and other agents can call your pipelines as tools, with their policies and spend limits still in force: at /mcp, or halo mcp over stdio.
    
              
    claude mcp add halo -- halo mcp ./pipelines
